# ggarciasoft website

The complete static website, including the SaaS projects section featuring Boletto and AdjudicaRD.

## Open locally

Extract this ZIP and open `index.html` in your browser.

Alternatively, serve the extracted folder:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Files

- index.html: page content
- style.css: responsive styles
- app.js: navigation, Agile tabs, and project brief download
- hero.webp: brand artwork

## Publish elsewhere

Upload these four website files to a static web host. No build step is required.

The typefaces load from Google Fonts and require an internet connection. System fonts are used if they are unavailable.
Project briefs download locally; they are not emailed or submitted.
